# Diccionario de datos — EcoConecta 360

18 tablas de aplicación; `alembic_version` es infraestructura. Fuente: `backend/models.py`; esquema inicial congelado en la revisión 0001. Todos los identificadores son BIGINT GENERATED BY DEFAULT AS IDENTITY. Las FKs usan NO ACTION: no se borran históricos en cascada.

Los timestamps de eventos usan TIMESTAMPTZ; PostgreSQL almacena el instante y la API exige zona al programar. UTC en almacenamiento/sesiones; presentación America/Bogota en el panel. Las reglas adicionales de triggers se explican en [arquitectura](arquitectura.md).
